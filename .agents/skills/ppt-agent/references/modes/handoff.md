# Handoff Mode

Use one selected Build, its Review, delivery preferences, and `visual-assets.md`. Re-verify the first/final accepted ImageGen evidence and refuse a handoff if either boundary or another required check fails. Package only the explicitly selected presentation files, together with the Review report, source provenance, boundary asset identities, and unresolved acceptance without overwriting an existing package. Exit with a Handoff manifest and concrete file paths.

If the selected Review contains fact-ledger evidence, copy its pinned ledger revision, evaluation time, claim states, source-integrity results and unresolved findings into the Handoff manifest. Do not re-evaluate a mutable ledger during packaging.
Before packaging, ask the user which currently available presentation formats they want: self-contained HTML, editable PowerPoint, PDF, or more than one. Do not infer a default from `Project.outputs`. Record the explicit selection with artifact type, source Build and frozen Version, actor, decision time, and conversation source. Package only selected formats. If an exporter is unavailable, say so plainly and offer the remaining choices without changing accepted work or converting one renderer into another.

Use `delivery-capabilities` against the selected Build, then `delivery-select` and `handoff-create --selection`. PDF eligibility requires a succeeded source Build with an accepted Review bound to the exact source hash. A PDF-only package contains the derivative and its traceability evidence, without adding an unselected HTML/PPTX. Offer the post-talk `handout` as a separate choice when the user plans to send material after the talk; never add it by default. It needs an accepted HTML Build. Ask whether they also want the audience edition (no speaker notes, transition pages merged, public governed citations only) and pass `--handout-editions speaker,audience`. If `delivery-capabilities` reports PDF or previews `unavailable`, say so before selection; the package records that status instead of substituting another exporter. Report `handout.status`, the PDF page-count checks and the script title check from the manifest. See `docs/handout.md`.

Missing native formats require a separate immutable Build from the same Frozen Version and its own Review; never overwrite the selected Build.
